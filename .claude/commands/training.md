# training

Safety training not current: SMS, human factors, investigation and dangerous goods by role, expired or never done first. --days=N shows anything expiring within N days; --all shows everyone.

Run `node scripts/safety.mjs training [--days=N] [--all]`. Add `--json` when you need every field. Resolve the report, hazard, action, person, aircraft or base by name first; if the CLI says a name is ambiguous, list the candidates and ask. Replace every angle-bracket value with a fact from the records or the operator. Never run a placeholder.
