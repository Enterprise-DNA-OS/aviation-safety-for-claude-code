# hazard

One hazard in full: its risk assessments over time, the reports linked to it and the actions against it.

Run `node scripts/safety.mjs hazard <ref or title>`. Add `--json` when you need every field. Resolve the report, hazard, action, person, aircraft or base by name first; if the CLI says a name is ambiguous, list the candidates and ask. Replace every angle-bracket value with a fact from the records or the operator. Never run a placeholder.

Show how the risk has moved, then what is still open.
