# report

One report in full: what happened, the notices owed to the CAA or ATSB and whether each was given, the investigation, its actions and its activity.

Run `node scripts/safety.mjs report <ref>`. Add `--json` when you need every field. Resolve the report, hazard, action, person, aircraft or base by name first; if the CLI says a name is ambiguous, list the candidates and ask. Replace every angle-bracket value with a fact from the records or the operator. Never run a placeholder.

Start with the notices owed, then the investigation, then the actions.
