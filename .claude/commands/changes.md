# changes

Every management of change record with its status, the hazards identified for it and their latest ratings, and open actions.

Run `node scripts/safety.mjs changes`. Add `--json` when you need every field. Resolve the report, hazard, action, person, aircraft or base by name first; if the CLI says a name is ambiguous, list the candidates and ask. Replace every angle-bracket value with a fact from the records or the operator. Never run a placeholder.

Say which proposed changes still need hazards identified and assessed.
